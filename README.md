# Homebrew Tap

## How do I install these formulae/casks?

`brew install diogowho/tap/<formula>`

`brew install --cask diogowho/tap/<cask>`

Or `brew tap diogowho/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "diogowho/tap"
brew "<formula>"
cask "<cask>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
