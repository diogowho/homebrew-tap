# Diogowho Tap

## How do I install these formulae?

`brew install diogowho/tap/<formula>`

Or `brew tap diogowho/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "diogowho/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
